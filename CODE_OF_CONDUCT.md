# Code of Conduct

## Our Pledge

We want participation in this project to be a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, appearance, race, religion, or sexual identity and orientation.

## Expected Behavior

- Be respectful and patient, especially with newcomers.
- Give and accept constructive feedback gracefully. Critique the change, not the person.
- Assume good faith, and ask when something is unclear.
- Keep discussion technical and on topic in issues and pull requests.

## Unacceptable Behavior

- Harassment, insults, personal attacks, or discriminatory language.
- Trolling, deliberate disruption, or sustained derailing of discussions.
- Publishing other people's private information without permission.
- Any conduct that would reasonably be considered inappropriate in a professional setting.

## Scope

This Code of Conduct applies in all project spaces (issues, pull requests, discussions, and reviews) and when someone represents the project in public.

## Reporting and Enforcement

Report conduct problems privately to **fabiomendes@mailfence.com**. Do not use public issues for this. Reports are handled confidentially, and the reporter's identity is not shared without consent. If a report concerns the maintainer, use GitHub's [Report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) option on the comment, issue, or pull request instead, which goes to GitHub Support.

Maintainers may edit or remove comments, close or lock threads, and temporarily or permanently ban anyone whose behavior breaks this Code of Conduct. Security vulnerabilities are a separate matter: follow [SECURITY.md](SECURITY.md).
